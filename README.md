# HR Analytics Dashboard (Power BI)

## 📊 Project Overview

This project analyzes employee attrition using Power BI. It helps identify key factors affecting employee turnover and supports data-driven decision-making.

## 🔧 Tools Used

* Power BI
* Power Query
* DAX

## 📈 Key Insights

* Employees with low salary have higher attrition
* Overtime leads to increased employee turnover
* Life Sciences field shows highest attrition
* Poor environment satisfaction leads to higher attrition

## 📊 Dashboard Features

* Salary vs Attrition Analysis
* Job Satisfaction Analysis
* Education Field Analysis
* Overtime, Work-Life Balance, Environment Analysis
* Interactive slicers (Gender, Department, Job Role, Education Field)
