
HR Analytics Dashboard (Power BI)
📊 Project Overview

This project analyzes employee attrition using Power BI. It helps identify key factors affecting employee turnover.

🔧 Tools Used

Power BI

Power Query

DAX

📈 Key Insights

Low salary employees have higher attrition

Overtime increases employee turnover

Life Sciences field has highest attrition

Poor environment satisfaction leads to attrition

📊 Dashboard Features

Salary vs Attrition Analysis

Job Satisfaction Analysis

Education Field Analysis

Overtime, Work-Life Balance, Environment Analysis

Interactive slicers (Gender, Department, Job Role, Education Field)
