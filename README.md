# HR Analytics Dashboard (Power BI)

## 📊 Project Overview
This project analyzes employee attrition using Power BI. The dashboard provides insights into factors affecting employee turnover.

## 🔧 Tools Used
- Power BI
- Power Query
- DAX

## 📈 Key Insights
- Employees with low salary show higher attrition
- Overtime leads to increased employee turnover
- Life Sciences field has highest attrition
- Poor environment satisfaction increases attrition

## 📊 Dashboard Features
- Attrition Analysis by Salary, Department, Job Role
- Employee Behavior Analysis (Overtime, Work-Life Balance)
- Interactive slicers (Gender, Department, Job Role, Education)
